# Token

Token management of the MS365 Integrations can be found on the MS365 Home Assistant [Token](https://rogerselwyn.github.io/MS365-HomeAssistant/token.html) page.

When Microsoft no longer accepts the token, or the client secret has expired, Home Assistant asks you to re-authenticate, see [Re-authentication](./authentication.md#re-authentication).
